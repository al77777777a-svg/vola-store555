# REVO Review Bot

A new REVO Discord bot for the review channel. It adds a reaction and sends the Revo separator. This version registers no slash commands.

## Railway variables

```text
DISCORD_TOKEN=your-new-bot-token
GUILD_ID=1447961768776437795
REVIEW_CHANNEL_ID=1547570950927687690
REVIEW_REACTION_ID=1477117835322069083
SEPARATOR_INTERVAL=1
SEPARATOR_ENABLED=true
```

Enable Message Content Intent in the Discord Developer Portal. Keep the token only in Railway as `DISCORD_TOKEN`; never commit it to GitHub.
